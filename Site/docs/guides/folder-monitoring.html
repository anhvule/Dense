Folder Monitoring

Point Dense at a folder, and anything new that shows up inside it compresses automatically — no dragging required after the initial setup.

Adding a watched folder

Open the advanced panel and find Watched folders, then click Add folder… to pick a directory. Each watched folder gets its own row with a preset picker and an on/off switch.

Per-folder presets

Every watched folder remembers its own preset (Discord, Email, YouTube, Web/Social, or any of the others) independently of whatever preset is currently selected on the destination dock. Dropping a file onto the dock manually is unaffected by a folder's watch preset, and vice versa.

Files already sitting in a folder when you start watching it are left alone — only files that arrive after watching begins get auto-compressed. This is deliberate: it avoids surprise mass-compression of an existing backlog the moment you turn watching on.

How arrivals are detected

Dense waits for a new file to sit still (no size changes) for about a second before enqueuing it, so a slow copy or download doesn't get grabbed half-written. Outputs the watcher itself creates are recognized and skipped, so it never re-compresses its own results in a loop.

Pausing, editing, and removing

Toggle a folder's switch off to pause watching without losing its configuration, change its preset at any time, or remove it entirely with the trash icon. If a watched folder is deleted on disk, its row shows a warning triangle and watching for it is skipped until the folder exists again.

Watched folders, their presets, and enabled state all persist across a relaunch.
