Folder Monitoring Coming soon

Not shipped yet — this page is a placeholder for a planned feature.

The idea: point Dense at a folder, and anything new that shows up inside it gets compressed automatically, using whatever preset you assign to that folder. No dragging required after the initial setup.

This isn't in the current release. Check the changelog for when it lands.

macOS 13+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
