Extract MP3

Grab just the audio from a video — a voice memo buried in a screen recording, a podcast recorded on camera, whatever you need without the picture.

How it works

Right-click a video row in the queue and choose Extract audio. Dense pulls the audio track out as a standalone file.

Format and fallback

Dense extracts to MP3 when possible. If the bundled FFmpeg build doesn't support the MP3 encoder, it automatically falls back to AAC in an .m4a container instead — you always get a working audio file either way, no manual encoder switching required.

This works on any video Dense can open — you don't need to compress the video first to extract its audio.

Output location, suffix, and cleanup

The extracted audio file follows the same shared Output and Suffix settings as everything else, and the source video can be moved to the Trash with Move to Trash after success if you no longer need it.

macOS 13+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
