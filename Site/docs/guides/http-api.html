Local HTTP API

A local HTTP API, bound to loopback only and gated behind a token, so scripts and other tools on your own Mac can queue compression jobs without opening the GUI.

Turning it on

In the advanced panel, flip Local API → Enable. It's off by default. Once enabled you'll see the port (default 4499, editable) and a bearer token, plus a ready-to-copy curl example.

The listener binds to 127.0.0.1 only — never a wildcard address — so it's unreachable from any other machine on your network, even before the OS firewall gets a say. It also only runs while explicitly enabled here.

Authentication

Every request needs an Authorization: Bearer <token> header. The token rotates every time the server (re)starts, including every app launch, and is never written to your Mac's preferences — it lives in memory and in a mode-0600 file at ~/Library/Application Support/Dense/api-token (readable only by you) for as long as the server is running, so scripts can read it without touching the UI.

Endpoints

POST /v1/compress — queues files for compression:

curl -s http://127.0.0.1:4499/v1/compress \
  -H "Authorization: Bearer <token>" \
  -H "Content-Type: application/json" \
  -d '{"paths":["/Users/me/clip.mp4"],"preset":"small"}'

paths must be absolute (a bare path or a file:// URL) and contain no .. components — traversal attempts are rejected outright, not silently resolved. preset is optional and matches the same preset names as deep links. The response reports how many files were accepted and which were skipped (missing, a directory, or an unsupported type).

GET /v1/jobs — returns the current job queue as JSON, including each job's status and, once done, its size savings.

Limits

Request bodies are capped at 1 MB (this is a control-plane protocol — paths and a preset name — not a bulk upload endpoint), at most 16 simultaneous connections are accepted, and an idle connection is dropped after 10 seconds. An API-triggered compress never changes your default preset in the app, same as a watched folder or a deep link.

macOS 14+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
