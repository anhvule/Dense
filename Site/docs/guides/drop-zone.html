Floating Drop Zone

A small, always-on-top circular drop target that floats above every window and every Space, so you can drag a file onto Dense without switching away from what you're doing.

Turning it on

Click the drop-zone icon in the main window's header to show or hide it. It defaults to the top-right corner of your screen the first time it appears; drag it anywhere afterward and Dense remembers the new position across relaunches.

Using it

Drop a file (or several) directly onto the circle. It compresses using whatever preset is currently selected on the destination dock — the same behavior as dropping onto the main window's background, not a specific dock card.

The drop zone stays visible even when Dense isn't the active app, and follows you across every Space, including other apps' full-screen Spaces — it's built to be there exactly when a drag needs somewhere to land.

Closing Dense's main window

The floating panel is independent of the main window, so closing the main window doesn't hide it — toggle it off from the header the next time you bring the main window forward.
