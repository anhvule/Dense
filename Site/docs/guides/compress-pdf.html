Compress a PDF

Dense compresses PDFs on Apple's native Quartz engine — nothing to install, and your text stays selectable.

No Ghostscript required

Some PDF compressors shell out to Ghostscript and ask you to install it separately. Dense doesn't — it uses macOS's built-in PDFKit/Quartz, so compression works the moment you drop a file in.

Quality tiers

The advanced panel's PDF quality picker offers three tiers, which control how aggressively embedded images are re-compressed and downsampled:

  • Good — JPEG quality 0.8, images downsampled to 300 DPI.
  • Balanced (default) — JPEG quality 0.6, 150 DPI.
  • Small — JPEG quality 0.4, 96 DPI, for the smallest possible file.

Real results measured on our fixtures: an image-heavy PDF shrank by 45%, 69%, and 89% across Good, Balanced, and Small respectively. A 4-page mixed text/image PDF went from 419 KB to 143 KB (−66%) at the default tier.

Text stays selectable

Dense re-compresses the embedded images inside a PDF, not the text layer — so text stays selectable and searchable after compression. It won't rewrite text as flattened images.

Current limits

  • Password-protected PDFs are unsupported. Dense reports this clearly rather than failing silently or hanging.
  • Text-only PDFs with no meaningful embedded images are left alone — if there's nothing to gain by re-compressing, Dense reports that the file wouldn't get smaller instead of doing a lossy rewrite for no benefit.
If a PDF is mostly scanned images, expect the biggest savings. If it's mostly typeset text, expect Dense to correctly tell you there's little to shrink.

Output location, suffix, and cleanup

Same shared options as every file type: Output (Next to original or a Custom folder), Suffix (default -compressed), and Move to Trash after success.

macOS 13+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
