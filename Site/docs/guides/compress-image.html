Compress an Image

Drop an image onto Dense to shrink it in place, with camera and location metadata kept intact.

Supported formats

JPEG, PNG, HEIC, TIFF, WebP, and BMP all compress directly — no conversion step needed.

Quality tiers

The advanced panel's Image quality picker offers three tiers:

  • Good — highest quality, smallest savings.
  • Balanced — the default middle ground for everyday sharing.
  • Small — maximum compression for the tightest file size.

EXIF and metadata

There's no separate metadata toggle — Dense preserves it automatically. Full-size re-encodes carry EXIF orientation, GPS coordinates, capture date, camera info, and color profile straight through. If you cap the resolution (shrinking dimensions, not just quality), orientation metadata is intentionally not re-copied — the resize step already bakes the correct orientation into the pixels, so copying it again would double-rotate the image.

Batch a whole folder of photos at once — each image compresses independently, so a single corrupt file won't stop the rest.

Smart names for images

An opt-in toggle in the advanced panel — off by default. When on, Dense uses on-device Vision image recognition to suggest a clearer filename for the compressed output, like beach-dog-2026-07-09.jpg instead of IMG_4821-compressed.jpg. Nothing leaves your Mac: classification runs entirely locally.

This only ever renames the compression output — your original file's name is never touched. If Dense can't confidently classify the image (or Vision has any trouble with it), the output keeps its normal suffixed filename — smart renaming never blocks or fails a job.

Output location, suffix, and cleanup

Same options as everywhere else in Dense: Output (Next to original or a chosen Custom folder), Suffix (default -compressed), and Move to Trash after success for the originals once you're happy with the result.

macOS 13+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
