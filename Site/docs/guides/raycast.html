Raycast Extension

Compress files straight from Raycast — pick a preset, done — without switching over to the Dense window.

Commands

  • Compress with Dense — takes your current Finder selection, filters it to file types Dense supports, and sends it over.
  • Compress Clipboard File — same idea, but for a single file path or file:// URL currently on your clipboard.

Both commands take a preset argument (Discord, Discord Nitro, Email, YouTube, Web/Social, High Quality, Balanced, or Small File — defaulting to Balanced) right in the Raycast command bar.

How it works

The extension builds a dense://compress link from your selection and opens it — Dense does the rest, exactly as if you'd dragged the files in yourself. Unsupported file types in a mixed selection are skipped with a note in the confirmation HUD rather than blocking the whole action.

If Dense isn't installed, Raycast shows a toast with a link to get it instead of failing silently.

Installing

Search the Raycast Store for "Dense" and install the extension, or, for local development, clone the extension from integrations/raycast/ in the Dense repo and run npx ray develop.

macOS 13+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
