Getting Started

Dense is a native Mac app — there's nothing to configure before your first compression.

Install

  1. Download Dense (link on the homepage) and drag it into /Applications.
  2. Open Dense. Since it's distributed outside the Mac App Store, the first launch may need a right-click → Open.
  3. Dense starts a 7-day full-feature trial automatically — no account, no email required to try it.

Compress your first file

  1. Drag a video, image, GIF, or PDF onto the Dense window.
  2. Drop it directly on one of the five destination cards — Discord, Email, YouTube, Web / Social, or Custom — to compress with that target in mind.
  3. Watch the file's row appear with a shrink-bar that fills in as compression finishes, showing the before/after size.
  4. The compressed file lands next to the original by default, with -compressed added to its name.
Drop a whole folder instead of a single file to queue everything inside it — see each guide's Advanced panel section for per-file overrides.

When the trial ends

Dense pauses new compressions until you activate a license. Anything already compressed is untouched. See pricing for license details.
