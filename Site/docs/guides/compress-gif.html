Compress a GIF

Already have a GIF that's too big to share? Drop it on Dense to re-palettize and, if needed, shrink its width.

What it does

Dense re-encodes the GIF's color palette to cut file size while keeping the same frame timing and loop — it doesn't force a new frame rate on an existing GIF, only a video-to-GIF conversion does that (see Video to GIF).

Advanced panel options

  • width — a stepper from 240 to 960 in steps of 80, default 480. If your GIF is wider than this, Dense rescales it down; narrower GIFs are left at their original width.
Re-palettization alone often cuts a chunky screen-recording GIF down significantly — try it before touching the width.

Output location, suffix, and cleanup

Same shared options as every other file type: Output (Next to original or a Custom folder), Suffix (default -compressed), and Move to Trash after success.

macOS 14+ · Apple Silicon & Intel. Dense uses FFmpeg under the GPL, run as a separate process — build sources: evermeet.cx (x86_64) and osxexperts.net (arm64).
