Deep Linking

A dense:// URL scheme so other apps, Shortcuts, or scripts can trigger a Dense compression job directly — no opening the app or dragging a file yourself required.

The URL format

Dense registers the dense://compress scheme and host. Give it one or more absolute path query items, plus an optional preset:

dense://compress?path=/Users/me/clip.mp4&preset=small

Multiple files in one link: repeat the path item.

dense://compress?path=/Users/me/a.mp4&path=/Users/me/b.jpg&preset=webSocial

Presets

The preset value matches one of Dense's internal preset names: discord, discordNitro, email, youtube, webSocial, high, balanced, or small. Omit it entirely to use whatever preset is currently selected in the app.

Encoding

Paths must be percent-encoded per RFC 3986 — spaces as %20, never +. A path that doesn't decode to an absolute filesystem path, or a link with no path items at all, is rejected with a rejection banner rather than silently doing nothing.

A link's preset never changes your default preset in the app — the same rule that applies to watched folders and the local HTTP API. It's a per-invocation choice made by whoever built the link, not a manual UI action.

Missing files

A path that parses fine but doesn't exist on disk shows up as its own failed row in the queue ("File not found") rather than blocking the rest of the link's files from processing.

This is exactly what the Raycast extension builds on top of.
